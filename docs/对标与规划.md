- **功能**：共梳理 98 项。已对齐 58、Web 专有 11、改造 7、部分 1、未做 10、不适用 11。

## 规范符合度

只列出不是“符合”的条款，完整清单见 Excel。

| 条款 | 要求 | 现状 | 结论 | 备注 |
| --- | --- | --- | --- | --- |
| §1.2 | 统一 ESM，根目录 package.json 声明 "type": "module" | 偏离 | ⚠️ | 基座启动时会在应用根目录放一个 CommonJS 文件 dh-identity-loader.js 并预加载；根目录声明 ESM 会报 “require is not defined in ES module scope”，应用起不来（1.0.0 实测）。因此根目录保持 CommonJS（run.js 是启动器），应用代码全部在 src/ 下并由 src/package.json 声明 ESM。建议平台把加载器改名为 .cjs，届时可改回 |
| §4.2 | 依赖白名单（建议）：fastify / pino / undici 等 | 部分 | ⚠️ | 完整包另有 exceljs、@tutao/oxmsg、acorn、jszip、@fastify/multipart；精简包只含白名单依赖。内网源缺包时用精简包 |
| §7.3 | 区域过滤（表含 region_code 时） | 不适用 | — | 当前表结构没有 region_code；启用区域权限时需补列并在 scoped.js 注入 |
| §7.4 | 统计用 SQL 聚合 | 部分 | ⚠️ | 报表趋势等沿用桌面版写法，部分在内存里聚合；数据量大时再优化 |
| §8.4 | 参数格式错误 422 | 部分 | ⚠️ | 1.6.0：请求体不是合法 JSON、参数类型不符返回 422；业务校验失败（缺字段、值不合法）仍返回 400。统一响应体下对前端无影响 |
| §9 | 基座不可用时 data.status | 偏离 | ⚠️ | 规范示例返回 fail（会触发重启）；本应用返回 ok，并把基座状态放在 base_api / data_mode，避免基座抖动时被反复重启。如平台要求严格按示例，改一行即可 |
| §12.1 | 视觉遵循数字人前端样式规范（浅色） | 偏离 | ⚠️ | 沿用桌面版 Dragon Claw 的视觉；是否需要换肤由平台确认 |
| §12.2 | API 基址按 location.pathname 拼接 | 部分 | ⚠️ | static/js/api.js 按规范写法；沿用自桌面版的页面仍含 /api/ 字面量，由运行时垫片统一改写。平台若做字面量扫描需再做一次机械替换 |
| §13.3 | package-lock 不指向公网源 | 部分 | ⚠️ | 地址已是内网源，但 lock 文件是在外网生成后替换地址得到的；需在内网机器上重新生成一次 |
| §16.2 | 端到端：门户前缀可访问、读写自身 schema、越权被拒 | 未验证 | ❓ | 已在模拟基座（真 MySQL 8 + 模拟网关）上通过；真实基座上未验证 |
