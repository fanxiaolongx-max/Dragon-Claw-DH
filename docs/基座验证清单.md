首次上基座时逐项验证，把结果填在“结果”列。第 5–8 项在右下角「调试模式」里有对应按钮。

| # | 验证内容 | 怎么验 | 通过标准 | 结果 |
| --- | --- | --- | --- | --- |
| 1 | 依赖安装 | 创建应用时的日志 | `npm ci` 成功；失败则改传精简包 | |
| 2 | 探活 | 观察 5 分钟 | 应用不被重启；`/api/healthz` 返回 `data.status = ok` | |
| 3 | 前缀 | 浏览器打开 `/digital-human/dh/{UUID}/` 和不带末尾斜杠的地址 | 首页样式、图标完整；各功能页能打开 | |
| 4 | 身份 | 调试模式 → 身份与环境 | “当前用户”显示自己的工号，来源为 `cookie:iLearningXUserName` | |

## 功能冒烟

空表状态下每个页面都应能打开并显示空态，不出现报错弹窗。

1. 数据导入：导入一份样例 Excel，生成快照。再导入一份上万行的大表，确认能保存、刷新页面后能读回（大字段分片）。
2. 报表看板：选择刚生成的快照入库，查看趋势。
3. 大屏看板、一键催办：能看到上一步的数据。
4. 月报：新建一份 AI 月报，编辑一个格子；经典月报能导出。
5. AI 对话：配置模型后发一条消息；换一个工号登录看不到这条会话。
   - 问“最新一期哪些指标没达标”，回答上方应出现「报表概览」「查询数据库」工具行，数字与报表看板一致。
   - 上传一个 Excel 附件并提问，应出现「读取文件」工具行。
   - 让它“做一个百分比计算器并发布”，发布后在首页「发现应用」里能打开。
   - 「技能·插件·工具」里能看到 7 个内置技能；在对话里输入 `@data-check` 能调用。
6. 权限：用非管理员工号打开，右下角没有调试按钮；修改全局配置被拒绝。
